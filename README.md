# Andruid's items

A lightweight Fabric mod that adds a small end‑game progression around ethereal residuum,
custom "ethereal" tools and armour with active abilities, a handful of utility blocks, and a bit of worldgen.

Highlights
- A resource loop: mine residuum, refine it into andid, and craft an andide block or a set of ethereal gear
- Ethereal tools (sword, axe, pick, spade, spear) with unique abilities on right‑click and sneak
- A full set of ethereal armour, plus an upgrade item to turn diamond gear ethereal
- Utility blocks: an ember block for long‑lasting fuel, and an experience block that bursts XP when broken
- World generation for ethereal residuum ore in the overworld and nether
- A few extras: druid's apple, seirei's leaf, a throwable fireball, seirei's flower, and two music discs

Getting started
1. Install Fabric Loader and Fabric API for Minecraft 26.1.
2. Download the latest Andruid's Items release jar and place it in your mods folder.
3. Launch the game. The mod id is moreitems; content appears in its own creative tab.

Features at a glance
- Resources and materials
  - Residuum (raw material) and refined andid
  - Storage blocks: andide, residuum block
  - Ores: ethereal residuum (overworld), nether ethereal residuum (nether)

- Gear
  - Ethereal tools: sword, axe, pick, spade, spear
    - Pick: mine a 3x3 area, or sneak right‑click to strip mine
    - Axe: freeze nearby mobs of the same kind, or sneak‑attack to launch and wither mobs nearby
    - Sword: right‑click for stacking speed, or sneak right‑click for temporary double health
  - Ethereal armour: helm, plate, leggings, boots
  - Ethereal upgrade: a smithing item that turns diamond armour into ethereal armour
  - Ability and info tooltips on supported items

- Utility and world
  - Experience block: breaks for a burst of XP, doesn't drop itself
  - Ember block: extremely hot, doubles as a long‑lasting fuel source
  - Seirei's flower and its potted variant: decorative, gives off a faint light
  - World generation for ethereal residuum ore in the overworld and nether

- Consumables and extras
  - Druid's apple and seirei's leaf: rare, effect‑granting food items
  - Fireball: a throwable item that launches a fireball projectile
  - Music discs: Royalty (Ezgod, Maestro Chives & Neoni) and Yokai's music disc (Formula by El Shaddai)
  - A set of mod‑specific advancements
